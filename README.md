# JESA Best Team Player Portfolio

An evidence-led, presentation-ready portfolio for Vihanga Rathnayake's JESA Best Team Player application.

## What this version prioritises

- Observable team behaviours aligned with the published JESA criterion
- Three structured collaboration stories with shared outcomes
- A candid growth reflection instead of title-focused claims
- Public evidence links and privacy-conscious referee handling
- A ten-minute presentation mode with timer and section controls

## Local development

```bash
npm install
npm run dev
```

The site is configured for GitHub Pages at `/jesa-team-player-portfolio/`.
